## Sobre el Proyecto

Novicompu es la mejor tienda de tecnología online en Ecuador. Encuentra una amplia selección de productos electrónicos incluyendo auriculares, monitores, cámaras de seguridad, laptops, tablets y teléfonos. Compra fácil y compara precios.

## Tecnologías Utilizadas

- **Astro**: Framework web para sitios rápidos centrados en contenido.
- **React**: Biblioteca para interfaces de usuario.
- **TailwindCSS**: Framework de utilidades CSS.
- **Lucide React**: Biblioteca de iconos.

## Desarrollo Local

Para ejecutar este proyecto localmente, sigue estos pasos:

1. Clonar el repositorio.
2. Instalar dependencias:

   ```bash
   bun install
   ```

3. Ejecutar el servidor de desarrollo:

   ```bash
   bun run dev
   ```

### Scripts Disponibles

- `bun run dev`: Inicia el servidor de desarrollo.
- `bun run build`: Construye el proyecto para producción.
- `bun run preview`: Vista previa de la construcción de producción.
- `bun run eslint`: Ejecuta el linter.
